# Beam Designer

Beam Designer is a Python Tkinter desktop app for analyzing simply supported
and cantilever beams. It calculates reactions, shear, moment, deflection,
bending stress, and passing sections, and displays interactive diagrams,
checks, and export options.

## Install

Install the required packages:

```powershell
pip install numpy matplotlib
```

Tkinter is included with most Python installations.

## Start

Run the app from this folder:

```powershell
python app.py
```

## Test

```powershell
python -m unittest -v
```
